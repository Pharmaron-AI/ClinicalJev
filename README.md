# ClinicalJev

**An open-source, all-purpose Jev for clinical and biomedical tasks.**

ClinicalJev is a research initiative to develop a broadly capable clinical Jev and a comprehensive benchmark for evaluating it. We want researchers to be able to assess performance across a wide range of medically meaningful tasks, specialties, and task formats using clear, reproducible evaluations.

## Planned releases

- **ClinicalJev:** an all-purpose clinical Jev, with model weights, inference code, and documentation.
- **ClinicalJev Benchmark:** a comprehensive benchmark, with task specifications, evaluation code, and reproducible results.

Our original model, benchmark materials, code, and documentation will be fully open source. Release links, version details, and licenses will be added here when they are available. Third-party resources, if included or referenced, remain subject to their original terms.

## Status

ClinicalJev and its benchmark are in development. No model or benchmark release is available yet.

## Research use

ClinicalJev is intended for research and evaluation. It is not a medical device or a substitute for professional clinical judgment.
